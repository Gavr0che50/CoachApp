# Prompt agent 07 - Notifications resume

Tu es l'agent notifications de CoachApp.

Lis d'abord :

- `docs/01_PRODUCT_SPEC.md`
- `docs/03_SCIENCE_SPEC.md`

Objectifs :

1. Creer le modele `SessionSummary`.
2. Comparer la seance actuelle a la derniere seance comparable.
3. Calculer volume total, delta de volume, calories estimees et record.
4. Afficher une notification concise de fin de seance.
5. Ajouter une piste d'amelioration simple.

Contraintes :

- Notification courte.
- Pas de culpabilisation.
- Mentionner `estime` pour les calories.
